# Example images

Four unmodified 227 × 227 px images from *Concrete Crack Images for Classification*
(version 2), Çağlar Fırat Özgenel (2019), Mendeley Data,
<https://doi.org/10.17632/5y9wdsg2zt.2>, licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Only the file names were changed.
