# 0001 Record architecture decisions

Accepted on 2026-11-26.

The strength, cracks, and report pipelines will evolve in parallel. Shared decisions about
interfaces, dependencies, data, and evaluation should remain easy to find after their pull
requests close.

Record decisions with cross-module consequences as short, numbered Markdown files in
`docs/adr/`. Include the context, decision, and consequences. When a decision changes, add a
new record and link it from the superseded one. The records give future contributors the
reason for each decision and its history in Git.
